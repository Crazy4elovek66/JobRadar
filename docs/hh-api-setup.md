# HH в JobRadar: HTML-режим и cookie

JobRadar больше не использует официальный REST API HeadHunter (`api.hh.ru`) и OAuth. Доступ к hh.ru идёт через обычные HTML-страницы:

- поиск вакансий: `https://hh.ru/search/vacancy`;
- карточка вакансии: `https://hh.ru/vacancy/{id}`;
- список резюме: `https://hh.ru/applicant/resumes`.

Для публичного поиска cookie обычно не обязательны. Для личных страниц, списка резюме и любых авторизованных действий нужен `HH_SESSION_COOKIE` из браузерной сессии hh.ru.

## Переменные `.env`

Минимальный набор для HH:

```env
HH_AREA=113
HH_HOST=hh.ru
HH_USER_AGENT="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0 Safari/537.36"
HH_SESSION_COOKIE=
HH_PROXY=
HH_PROXIES=
HH_PROXY_FILE=good_proxies.txt
HH_PROXY_MODE=direct_then_proxy
```

`HH_SESSION_COOKIE` вставляется как значение HTTP-заголовка `Cookie`, без префикса `Cookie:`. Реальные cookie нельзя коммитить и нельзя отправлять посторонним.

## Как получить cookie

1. Откройте hh.ru в браузере и войдите в нужный аккаунт.
2. Перейдите на `https://hh.ru/applicant/resumes`.
3. Откройте инструменты разработчика: `F12` или `Ctrl+Shift+I`.
4. Откройте вкладку Network / «Сеть».
5. Обновите страницу.
6. В списке запросов выберите документ `resumes` или запрос к `https://hh.ru/applicant/resumes`.
7. В Request Headers / «Заголовки запроса» найдите строку `Cookie`.
8. Скопируйте только значение после `Cookie:`.
9. Вставьте в `.env`:

```env
HH_SESSION_COOKIE=ваши_cookie_целиком_в_одну_строку
```

Если в cookie есть пробелы или специальные символы, можно обернуть значение в двойные кавычки:

```env
HH_SESSION_COOKIE="key1=value1; key2=value2; key3=value3"
```

После изменения `.env` перезапустите JobRadar.

## Проверка

В Telegram откройте раздел «HH подключение» и нажмите «Проверить подключение». Для подробной проверки используйте команду:

```text
/hh_diag
```

Диагностика проверит:

- открывается ли HTML-поиск вакансий;
- принял ли HH cookie для страницы резюме;
- какой маршрут использовался: прямой или прокси.

Если HH вернул 403, обновите cookie и проверьте сетевой маршрут. Если браузер открывает hh.ru через один VPN/прокси, а JobRadar идёт другим маршрутом, HH может считать сессию подозрительной.

## Отклики

Автоотклики через HTML-версию сейчас отключены. JobRadar показывает вакансию и ссылку на HH, а реальный отклик нужно отправлять вручную на странице вакансии.

Причина: форма отклика на hh.ru зависит от текущей страницы, CSRF-токенов, состояния резюме, тестов и антибот-проверок. Лучше явно остановить автоматический POST, чем отправлять хрупкий запрос с непредсказуемым результатом.

## Прокси

Если HH блокирует текущий IP, можно задать отдельный маршрут:

```env
HH_PROXY=http://login:password@ru-proxy.example:8080
```

Несколько прокси можно указать через запятую в `HH_PROXIES` или положить в файл `good_proxies.txt`. Порядок маршрутов задаёт `HH_PROXY_MODE`:

- `direct_only`;
- `proxy_only`;
- `proxy_then_direct`;
- `direct_then_proxy`.
