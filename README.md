# JobRadar

JobRadar - простой Telegram-бот для поиска вакансий, которые могут стать входом в IT. Он ищет вакансии через HH.ru API, отсекает колл-центры, продажи и горячие линии, оценивает IT-релевантность и присылает только подходящие варианты.

Проект сделан как практичный MVP: бесплатно, без браузерного парсинга, без платных API, без нейросетей и без тяжёлых фреймворков.

## Для чего проект

JobRadar помогает найти работу за компьютером с реальными техническими задачами: QA, helpdesk, service desk, поддержка IT-продукта, CRM, интеграции, автоматизация, junior Python, мониторинг и смежные направления.

Главный принцип: лучше 5 нормальных IT-вакансий, чем 100 вакансий из колл-центров.

## Установка

Нужен Python 3.11 или новее.

```bash
pip install -r requirements.txt
```

## Как создать Telegram-бота

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте команду `/newbot`.
3. Задайте название и username бота.
4. Скопируйте токен, который выдаст BotFather.
5. Узнайте свой Telegram ID, например через бота `@userinfobot`.

## Настройка `.env`

Скопируйте пример:

```bash
cp .env.example .env
```

На Windows можно просто создать рядом файл `.env` и перенести туда значения из `.env.example`.

Заполните:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_USER_ID=ваш_telegram_id
HH_AREA=113
HH_HOST=hh.ru
HH_USER_AGENT="JobRadar/1.0 (email@example.com)"
HH_CLIENT_ID=""
HH_CLIENT_SECRET=""
HH_ACCESS_TOKEN=""
HH_REDIRECT_URI="https://your-project.vercel.app/auth/hh/callback"
HH_PROXY=
HH_PROXIES=
HH_PROXY_FILE=good_proxies.txt
TELEGRAM_PROXY=
SEARCH_INTERVAL_MINUTES=180
MIN_SCORE_TO_SEND=60
DATABASE_PATH=data/jobradar.db
```

`HH_AREA=113` означает Россию. Регион можно поменять на другой ID из справочника HH.ru. `HH_HOST=hh.ru` выбирает сайт группы HeadHunter для API-запросов. Для поиска по России оставьте `HH_HOST=hh.ru`.

Подробная инструкция по официальному подключению hh.ru API лежит в `docs/hh-api-setup.md`.

Если HH.ru возвращает 403 из-за зарубежного маршрута, задайте для HH отдельный российский HTTP-прокси:

```env
HH_PROXY=http://login:password@ru-proxy.example:8080
```

Можно указать несколько прокси через запятую в `HH_PROXIES` или положить список в файл `good_proxies.txt`. Бот будет пробовать маршруты по очереди и перестанет использовать те, на которых HH вернул 403. `TELEGRAM_PROXY` настраивает только Telegram и не влияет на запросы к HH.

Проверить список прокси можно командой:

```bash
python proxy_checker.py
```

Проверить API, User-Agent и токен можно командой:

```bash
python check_hh_api.py
```

Если API HH блокирует поиск вакансий, но обычный сайт `hh.ru` открывается, JobRadar автоматически переключится на HTML-поиск. Это запасной режим для домашнего российского подключения: он медленнее API, но позволяет продолжать поиск без внешнего прокси.

## Лендинг для dev.hh.ru

В проект добавлен отдельный лендинг в папке `web`. Его можно задеплоить на Vercel и указать при регистрации приложения в dev.hh.ru.

Локальный запуск:

```bash
cd web
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Для Vercel укажите `Root Directory = web`. После деплоя используйте:

- URL сайта: главная страница лендинга.
- Redirect URL: `https://your-project.vercel.app/auth/hh/callback`.

## Запуск

```bash
python main.py
```

После запуска бот отвечает на команды и раз в несколько часов сам проверяет новые вакансии.

## Команды бота

- `/start` - приветствие и краткое описание.
- `/search` - ручной поиск свежих вакансий.
- `/stats` - статистика базы: сколько найдено, отправлено и отсеяно.
- `/settings` - текущие настройки и поисковые запросы.
- `/help` - подсказка по командам.

## Как работает scoring

Каждая вакансия получает:

- `score` от 0 до 100;
- статус `HOT`, `GOOD`, `MAYBE` или `REJECT`;
- карьерную пользу от 1 до 10;
- список плюсов и рисков.

Плюсы начисляются за удалёнку, IT-продукт, QA, баг-репорты, тикеты, Jira, Helpdesk, Service Desk, CRM, Bitrix24, amoCRM, API, SQL, Python, скрипты, автоматизацию, диагностику, логи и обучение.

Минусы начисляются за офис без удалёнки, высокий опыт, обязательное высшее образование, тяжёлые смены и клиентский сервис без технической части.

Жёсткие стоп-факторы сразу отклоняют вакансию: горячая линия, колл-центр, входящие или исходящие звонки, холодные звонки, телефонные продажи, обзвон клиентов, работа по скрипту.

## Как добавить новые поисковые запросы

Откройте файл `src/scoring.py` и добавьте фразы в список `SEARCH_QUERIES`.

Пример:

```python
SEARCH_QUERIES = [
    "junior qa",
    "техническая поддержка it",
    "ваш новый запрос",
]
```

После перезапуска бот начнёт использовать новые запросы.

## Где хранится база

SQLite-база создаётся по пути из `DATABASE_PATH`, по умолчанию:

```text
data/jobradar.db
```

В базе сохраняются найденные вакансии, оценки, причины, дата первого появления, дата последней проверки, дата отправки, избранное и ручные отклонения.

Если вакансия уже была отправлена, бот не пришлёт её повторно. Если нажать «Не подходит», вакансия больше не будет отправляться.

## Как в будущем добавить новые источники

SuperJob:
можно добавить отдельный клиент по аналогии с `src/hh_client.py`, если выбранный API-доступ остаётся бесплатным и стабильным.

Avito:
лучше не добавлять в MVP. Там выше риск блокировок и сложнее сделать бесплатную стабильную реализацию без браузерного парсинга.

Хабр Карьера:
можно добавить отдельный клиент, если доступ к вакансиям получится получать легально и стабильно без тяжёлого парсинга.

Для нового источника лучше сохранить общий поток:

```text
источник вакансий -> Vacancy -> calculate_score -> SQLite -> Telegram
```

Так scoring и защита от дублей останутся общими.
